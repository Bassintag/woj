# Features

## Lister toutes les recettes

Pour chaque recette afficher :

    - les calories par portion
    - le nom de la recette
    - l'image de la recette
    - temps de préparation

## Rechercher par nom

On doit pouvoir rechercher sur le nom de la recette et ses ingrédients. L'affichage ressort par pertinance (nom correspond puis ingrédient correspond) puis pas ordre alphabétique

## Filtre des recettes

Tags

## Afficher les détails d'un recette

Afficher :

- le titre de la recette
- l'image de la recette
- les tags
- le temps de préparation
- le temps de cuisson
- les calories par portion
- le nombre de portions : modifiable avec mise à jour auto de la liste des ingrédients
- la liste des ingrédients
- les étapes de réalisation

## Créer une recette

On doit pouvoir créer une recette avec les données suivantes :

- le titre de la recette
- l'image de la recette
- le temps de préparation
- le temps de cuisson
- le nombre de portions pour les quantités initiales de la recette
- la liste des ingrédients (On peut ajouter autant d'ingrédients qu'on veut et on peut seulement ajouter des ingrédients existants)
- les étapes de réalisation (on peut ajouter autant d'étapes qu'on veut)
- les tags

=> Les calories par portion sont calculées automatiquement

## Créer un ingrédient

Un ingrédient doit contenir :

- un nom
- une image
- les calories par 100g
- liste d'unités pour l'ingrédient avec taux de conversion pour l'unité de base

## Créer un menu

Donner un titre au menu.
Dans un menu, on peut ajouter autant de recette qu'on veut et indiquer le nombre de portions pour chaque recette.

## Créer une liste de courses

On doit pouvoir créer une liste de course à partir d'un menu. On doit aussi pouvoir créer une nouvelle liste et ajouter des recettes à cette liste depuis la liste des recettes ou le détail d'une recette. On doit pouvoir modifier le nombre de portions pour chaque recette et valider la liste.
